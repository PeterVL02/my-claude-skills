# my-claude-skills

Custom (mostly vibe-coded, but reviewed) [Claude Code](https://claude.com/claude-code) skills.

| Skill | Description |
|-------|-------------|
| [ml-workflow](ml-workflow/) | Keeps AI/ML/data-science projects healthy: pipelines, sanity checks, research, a project log, git hygiene, tests and CI. |

Each skill's own README has the install and usage steps. In short: clone this repo, then link or copy the skill's inner folder (the one that contains `SKILL.md`) to `~/.claude/skills/<name>/`.
